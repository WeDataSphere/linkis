## 一、测试概述

### 1.1 测试目标

本次测试覆盖配置参数删除功能的所有核心场景，包括：
- UI元素显示与交互
- 权限控制（管理员/普通用户）
- 删除确认流程
- 删除成功/失败场景
- 异常处理（网络异常、后端错误）
- 与现有功能的兼容性

### 1.2 测试范围

| 包含内容 | 不包含内容 |
|---------|-----------|
| ✅ 删除按钮UI显示与隐藏 | ❌ 批量删除功能 |
| ✅ 权限控制测试 | ❌ 删除历史记录 |
| ✅ 删除确认对话框 | ❌ 配置参数回收站 |
| ✅ 删除成功/失败场景 | ❌ 后端接口新增（使用现有接口） |
| ✅ 网络异常处理 | ❌ |
| ✅ 与高级设置兼容性 | ❌ |

### 1.3 测试策略

**测试类型分布**：
- **UI界面测试**: 40% - 前端界面元素、交互效果
- **功能测试**: 40% - 核心业务功能、权限控制
- **异常测试**: 20% - 网络异常、后端错误

**测试优先级分布**：
- **P0 (critical)**: 核心功能、权限控制、删除成功流程
- **P1 (important)**: 交互效果、异常处理
- **P2 (boundary)**: 边界场景、兼容性测试

## 二、UI界面测试用例

### TC-UI-001: 管理员查看配置参数时显示删除按钮

**来源**：Feature文件 - 配置参数删除功能.feature, 场景 2

**测试类型**：UI界面测试 🆕

**测试场景**: 验证管理员用户登录后，配置项右侧显示删除按钮

**前置条件**：
- 用户已登录 Linkis 系统
- 用户拥有管理员权限（`isLogAdmin` 为 true）
- 用户进入配置管理（Setting）页面
- 当前显示至少一个配置参数列表

**测试步骤**：
1. 以管理员身份登录系统
2. 进入配置管理（Setting）页面
3. 切换到任一应用/引擎配置标签页（如 "LINKISCLI"）
4. 观察配置参数列表中每个配置项的右侧

**预期结果**：
- 每个配置项右侧显示删除按钮（红色垃圾桶图标）
- 删除按钮仅在管理员权限下可见
- 删除按钮位于配置项行的最右侧
- 删除按钮与配置值输入框对齐

**测试数据**：
```javascript
// 配置项示例
{
  name: "Spark Executor 内存",
  key: "spark.executor.memory",
  value: "2g"
}
```

**优先级**：P0
**测试类型**：UI界面测试

**Gherkin规格** 🆕：
```gherkin
Scenario: 管理员查看配置参数时显示删除按钮
  Given 用户是管理员
  And 配置参数列表中有配置项 "spark.executor.memory"
  When 用户查看配置参数列表
  Then 每个配置项右侧应显示删除按钮（红色垃圾桶图标）
  And 删除按钮仅在管理员权限下可见
```

### TC-FUNC-001: 管理员成功删除配置参数

**来源**：Feature文件 - 配置参数删除功能.feature, 场景 4

**测试类型**：功能测试 🆕

**测试场景**: 验证管理员成功删除配置参数的完整流程

**前置条件**：
- 用户是管理员
- 配置参数列表中有配置项 "spark.executor.memory"
- 用户已进入配置管理页面

**测试步骤**：
1. 用户点击配置项 "spark.executor.memory" 的删除按钮
2. 系统弹出确认对话框
3. 验证对话框标题为 "确认删除配置参数"
4. 验证对话框内容包含 "删除配置参数 spark.executor.memory 将会影响所有用户使用此配置，且不可恢复"
5. 用户点击 "确定" 按钮
6. 观察列表变化和提示信息

**预期结果**：
- 该配置项从列表中移除
- 系统显示成功提示 "删除配置参数成功"
- 后端 API `/configuration/keyvalue` 被正确调用
- 请求参数包含 `configKey="spark.executor.memory"`, `creator="LINKISCLI"`, `engineType="spark"`, `version="*"`

**API调用验证**：
```javascript
// 预期的API调用
DELETE /configuration/keyvalue
{
  "configKey": "spark.executor.memory",
  "creator": "LINKISCLI",
  "engineType": "spark",
  "version": "*"
}
```

**优先级**：P0
**测试类型**：功能测试

**Gherkin规格** 🆕：
```gherkin
Scenario: 管理员成功删除配置参数
  Given 用户是管理员
  And 配置参数列表中有配置项 "spark.executor.memory"
  And 用户点击该配置项的删除按钮
  When 系统弹出确认对话框
  And 对话框标题为 "确认删除配置参数"
  And 对话框内容包含 "删除配置参数 spark.executor.memory 将会影响所有用户使用此配置，且不可恢复"
  And 用户点击 "确定" 按钮
  Then 该配置项从列表中移除
  And 系统显示成功提示 "删除配置参数成功"
  And 后端 API "/configuration/keyvalue" 被正确调用
  And 请求参数包含 configKey="spark.executor.memory"
```

1. **后端权限校验**：现有后端接口 `/configuration/keyvalue` 无管理员权限校验，权限控制完全依赖前端
2. **批量删除**：当前版本不支持批量删除功能
3. **删除范围**：删除的是配置值（Value），不是配置键（Key），配置键定义保留

### 13.4 测试风险

| 风险项 | 风险等级 | 缓解措施 |
|-------|:-------:|---------|
| 删除重要配置参数导致系统异常 | 高 | 测试时使用测试专用配置项，避免删除核心参数 |
| 前端权限控制被绕过 | 中 | 后续版本可在后端增加权限校验 |
| 网络异常导致数据不一致 | 低 | 前端在删除成功后才移除配置项 |
