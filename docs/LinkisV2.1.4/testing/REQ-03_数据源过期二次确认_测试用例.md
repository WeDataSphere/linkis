## 一、测试概述

### 1.1 测试范围

本测试用例覆盖管理台数据源列表"过期"按钮二次确认功能的全部必测项和选测项，基于 Stage 5.5 测试澄清纪要确认的 testScope 生成。

| 范围类型 | 数量 | 说明 |
|---------|------|------|
| 必测项 (mustTest) | 10 | AC1-AC4 全覆盖 + 功能点 F-2/F-3 状态与逻辑断言 |
| 选测项 (optionalTest) | 4 | 边界与异常场景 |
| 不测项 (notTest) | 4 | 后端接口、附带变更、非本次改动功能 |
| **总计** | **14** | 必测 10 + 选测 4 |

### 1.2 测试数据策略

| 数据项 | 构造方法 | 依赖 | 清理策略 |
|--------|----------|------|----------|
| 至少一条有效数据源 | 通过管理台"创建数据源"功能或 DB 直接插入 | 数据源类型已配置 | 测试结束后删除或过期创建的测试数据源 |
| 数据源名称含特殊字符（可选） | 创建数据源时使用特殊字符名称 | 无 | 同上 |
| 空名称数据源（选测） | DB 直接插入 name 为空的数据源记录 | 无 | 测试后删除 |

### 1.3 环境与鉴权

| 维度 | 内容 |
|------|------|
| 前端管理台 | 需部署 linkis-web 前端至 SIT 环境（提测后确认地址） |
| 后端 API | 与前端同环境部署的 linkis-server |
| 登录方式 | 管理台账密登录（Linkis 管理台标准登录流程） |
| 权限要求 | 测试账号需具备数据源管理模块的查看和操作权限 |
| VPN | 需内网访问 |

### TC001: 点击过期按钮弹出二次确认 Modal

**来源**: 必测项 #1 (AC1) - acceptance_criteria

- Modal 可见且处于模态遮挡状态

**测试数据**:

## 五、注意事项

1. **环境依赖**: 本测试需在 SIT 环境部署 linkis-web 前端管理台后执行，提测前可使用占位符地址。
2. **测试数据清理**: 测试过程中创建的数据源记录需在测试结束后删除或过期。
3. **i18n 切换**: 中英文切换测试需确认管理台语言切换功能正常。
4. **Vue DevTools**: TC009 和 TC014 依赖 Vue DevTools 检查组件内部状态，需在浏览器中安装 Vue 开发者工具插件。
5. **Network 面板**: TC004、TC005、TC010 依赖 Network 面板验证接口调用情况。
6. **接口 Mock**: TC012 需要模拟 expire 接口失败，可通过 mock 工具或断开后端服务实现。
