## 一句话概括

- **正常引擎（Computation）**：常驻进程，启动后"待命"，由 Entrance 通过 RPC **被动**推送任务，可复用执行多个任务。
- **Once 引擎**：启动即"干活"，任务内容在启动参数里带过来，**执行完这一个任务就退出**。
