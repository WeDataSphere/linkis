## 添加新的 MCP 服务器

如果需要添加新的 MCP 服务器，配置格式如下：

### HTTP 类型（如您现有的）
```json
"mcpServers": {

    "headers": {
      "Authorization": "Bearer token"
    },
    "timeout": 60
  }
}
```

### Stdio 类型（本地进程）
```json
"mcpServers": {
  "server-name": {
    "command": "npx",
    "args": ["-y", "@anthropic/mcp-server"],
    "env": {
      "API_KEY": "your-key"
    }
  }
}
```
