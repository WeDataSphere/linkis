## copy-keytab-files 接口文档

### 基本信息

| 项目 | 说明 |
|------|------|
| **接口名称** | copy-keytab-files |
| **接口路径** | `/filesystem/copy-keytab-files` |
| **请求方式** | GET |
| **所属模块** | linkis-pes-publicservice |
| **Controller** | [FsRestfulApi.java:1699-1787](linkis-public-enhancements/linkis-pes-publicservice/src/main/java/org/apache/linkis/filesystem/restful/api/FsRestfulApi.java#L1699) |

### 功能描述

从 HDFS 源目录复制 Kerberos keytab 文件到 Linkis 目标目录，并在复制过程中对文件内容进行 AES 加密。该接口主要用于 Kerberos 认证场景下的 keytab 文件安全管理。

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| user | String | 否 | 指定要复制的用户名（按用户名过滤 keytab 文件） |

### 请求示例

```
GET /filesystem/copy-keytab-files?user=hadoop
```

或复制所有用户的 keytab 文件：

```
GET /filesystem/copy-keytab-files
```
