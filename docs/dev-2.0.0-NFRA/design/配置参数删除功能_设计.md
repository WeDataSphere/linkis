## 一、设计概述

### 1.1 设计目标

为Linkis配置管理（Setting）模块新增单个配置参数删除功能，实现：
- **精细化管理**：支持Key-Value级别的配置删除
- **权限安全**：仅管理员可执行删除操作
- **用户友好**：提供清晰的确认对话框和操作反馈

### 1.2 设计范围

| 包含内容 | 不包含内容 |

| ✅ 前端删除按钮UI实现 | ❌ 批量删除功能 |
| ✅ 权限控制（管理员校验） | ❌ 删除历史记录功能 |
| ✅ 删除确认对话框 | ❌ 配置参数回收站 |
| ✅ 后端API接口定义 | ❌ 配置导出/导入功能 |
| ✅ 前后端联调逻辑 | ❌ |

#### 3.2.2 Setting组件改造

**文件路径**: `linkis-web/src/apps/linkis/module/setting/setting.vue`

**模板修改**:
```vue
<template>
  <div class="setting-content">
    <variable
      v-for="(item, index) in fullTree"
      :key="index"
      :variable="item"
      @add-item="handleAdd"
      @remove-item="handleDelete"
      @delete-config-item="handleDeleteConfigItem"
    />
  </div>
</template>
```

**新增方法**:
```javascript
methods: {
  /**
   * 处理配置项删除
   * @param {Object} configItem - 要删除的配置项
   * @param {String} configItem.key - 配置Key
   * @param {String} configItem.name - 配置名称
   */
  async handleDeleteConfigItem(configItem) {
    try {
      // 显示加载提示
      this.$Message.loading({
        content: '正在删除配置参数...',
        duration: 0
      });

      // 调用后端API（使用现有DELETE接口）
      await this.deleteConfigValueAPI({
        configKey: configItem.key,
        creator: this.currentTabName,
        engineType: this.getCurrentEngineType() || '*',
        version: '*'
      });

      // 关闭加载提示
      this.$Message.destroy();

      // 从本地数据中移除该配置项
      this.removeConfigFromTree(configItem.key);

      // 显示成功提示
      this.$Message.success('删除配置参数成功');
    } catch (error) {
      // 关闭加载提示
      this.$Message.destroy();

      // 显示错误提示
      this.$Message.error(`删除配置参数失败：${error.message || error.response.data.message}`);
    }
  },

  /**
   * 删除配置值 API调用（使用现有接口）
   */
  deleteConfigValueAPI(params) {
    return api.fetch('/configuration/keyvalue', params, 'delete');
  },

  /**
   * 从本地树结构中移除配置项
   */
  removeConfigFromTree(configKey) {
    this.fullTree.forEach(tree => {
      const index = tree.settings.findIndex(setting => setting.key === configKey);
      if (index !== -1) {
        tree.settings.splice(index, 1);
      }
    });
  },

  /**
   * 获取当前引擎类型
   */
  getCurrentEngineType() {
    if (this.subCategory[this.currentTabName]) {
      return this.subCategory[this.currentTabName].categoryName;
    }
    return null;
  }
}
```

## 四、后端接口说明

### 4.1 使用现有接口

本功能使用现有删除接口，无需开发新后端代码。

#### 4.1.1 接口基本信息

**接口路径**: `DELETE /configuration/keyvalue`

**接口位置**: 
- `ConfigurationRestfulApi.deleteKeyValue()`
- `linkis-public-enhancements/linkis-configuration/src/main/java/org/apache/linkis/configuration/restful/api/ConfigurationRestfulApi.java`

**请求参数**:
```json
{
  "configKey": "wds.linkis.rm.yarnqueue.memory.max",
  "creator": "LINKISCLI",
  "engineType": "hive",
  "version": "*"
}
```

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|-------|------|------|------|--------|
| configKey | String | ✅ | 配置参数的Key | wds.linkis.rm.yarnqueue.memory.max |
| creator | String | ❌ | 应用方（Creator），默认为"*" | LINKISCLI |
| engineType | String | ❌ | 引擎类型，默认为"*" | hive |
| version | String | ❌ | 版本号，默认为"*" | * |

#### 4.1.2 接口功能说明

**删除范围**：
- 删除的是配置值（Value），不是配置键（Key）
- 配置键定义保留在 `linkis_ps_configuration_config_key` 表中
- 仅删除 `linkis_ps_configuration_key_value` 表中的配置值记录

**权限说明**：
- 现有接口无管理员权限校验
- 所有登录用户均可调用
- 权限控制完全依赖前端

**成功响应**:
```json
{
  "method": "/configuration/keyvalue",
  "status": 0,
  "message": "OK",
  "data": {
    "configValues": [...]
  }
}
```

**失败响应类型**:

1. **Key为空**:
```json
{
  "method": "/configuration/keyvalue",
  "status": 1,
  "message": "key cannot be empty"
}
```

2. **参数组合错误**:
```json
{
  "method": "/configuration/keyvalue",
  "status": 1,
  "message": "When engineType is any engine, the version must also be any version"
}
```

### 4.2 现有实现说明

#### 4.2.1 Service层实现

**接口**: `ConfigKeyService`

**方法**: `List<ConfigValue> deleteConfigValue(String key, List<Label<?>> labelList)`

**实现位置**: 
- `ConfigKeyServiceImpl.deleteConfigValue()`
- `linkis-public-enhancements/linkis-configuration/src/main/java/org/apache/linkis/configuration/service/impl/ConfigKeyServiceImpl.java`

**实现逻辑**:
```java
@Override
public List<ConfigValue> deleteConfigValue(String key, List<Label<?>> labelList)
    throws ConfigurationException {
    CombinedLabel combinedLabel = getCombinedLabel(labelList);
    List<ConfigValue> configValues = getConfigValue(key, labelList);
    for (ConfigValue configValue : configValues) {
      configMapper.deleteConfigKeyValue(configValue);
    }
    logger.info("succeed to remove key: {} by label:{} ", key, combinedLabel.getStringValue());
    return configValues;
}
```

**说明**：
- 该方法删除指定Key和Label组合的配置值
- 配置键定义保留
- 删除操作仅针对配置值表（`linkis_ps_configuration_key_value`）

#### 4.2.2 数据库操作

**涉及表**: `linkis_ps_configuration_key_value`

**删除SQL**: 
```xml
<delete id="deleteConfigKeyValue">
  DELETE FROM linkis_ps_configuration_key_value
  WHERE id = #{id}
</delete>
```

**说明**：
- 仅删除配置值记录
- 配置键表（`linkis_ps_configuration_config_key`）不受影响
- 删除后前端通过重新加载列表，该配置项不再显示

## 五、异常处理设计

### 5.1 前端异常处理

#### 5.1.1 异常类型与处理策略

| 异常类型 | 触发场景 | 处理策略 |
|---------|---------|---------|
| **权限异常** | 非管理员点击删除 | 前端拦截，显示"无权限操作"提示 |
| **网络异常** | 请求超时、网络断开 | 显示"网络异常，请稍后重试"，保持配置项不变 |
| **业务异常** | 后端返回业务错误 | 显示后端错误信息，保持配置项不变 |
| **系统异常** | 服务器错误(500) | 显示"系统异常，请联系管理员" |

#### 5.1.2 异常处理代码

```javascript
async handleDeleteConfigItem(configItem) {
  try {
    // 1. 权限校验（前端）
    if (!this.isLogAdmin) {
      throw new Error('无权限操作，仅管理员可删除配置参数');
    }

    // 2. 显示加载提示
    const loadingMsg = this.$Message.loading({
      content: '正在删除配置参数...',
      duration: 0
    });

    // 3. 调用后端API（使用现有DELETE接口）
    await this.deleteConfigValueAPI({
      configKey: configItem.key,
      creator: this.currentTabName,
      engineType: this.getCurrentEngineType() || '*',
      version: '*'
    });

    // 4. 关闭加载提示
    this.$Message.destroy();

    // 5. 移除本地配置项
    this.removeConfigFromTree(configItem.key);

    // 6. 显示成功提示
    this.$Message.success('删除配置参数成功');

  } catch (error) {
    // 关闭加载提示
    this.$Message.destroy();

    // 异常分类处理
    let errorMessage = '删除配置参数失败';

    if (error.response) {
      // 后端返回的错误
      const status = error.response.status;
      const backendMessage = error.response.data?.message;

      if (status === 401) {
        errorMessage = '无权限操作，仅管理员可删除配置参数';
      } else if (status === 400) {
        errorMessage = backendMessage || '请求参数错误';
      } else if (status === 404) {
        errorMessage = '配置参数不存在';
      } else if (status === 500) {
        errorMessage = '系统异常，请联系管理员';
      } else {
        errorMessage = backendMessage || `删除失败：${status}`;
      }
    } else if (error.request) {
      // 网络异常
      errorMessage = '网络异常，请稍后重试';
    } else {
      // 其他错误
      errorMessage = error.message || '未知错误';
    }

    // 显示错误提示
    this.$Message.error(errorMessage);

    // 记录错误日志
    console.error('删除配置参数失败：', error);
  }
}
```

### 5.2 后端异常处理

**说明**：本功能使用现有后端接口，异常处理已包含在现有实现中。

**现有接口异常类型**：

## 七、性能与安全设计

### 7.1 性能优化

#### 7.1.1 前端性能优化

| 优化项 | 实现方式 | 预期效果 |
|-------|---------|---------|
| **懒加载** | 删除按钮仅在需要时渲染 | 减少初始渲染时间 |
| **防抖处理** | 删除操作添加防抖（300ms） | 防止重复点击 |
| **局部更新** | 使用Vue的响应式系统局部更新配置项 | 避免整个列表重新渲染 |

#### 7.1.2 后端性能优化

| 优化项 | 实现方式 | 预期效果 |
|-------|---------|---------|
| **批量删除** | 单次API调用仅删除单个配置 | 未来可扩展批量删除 |
| **异步日志** | 操作日志异步写入 | 不阻塞主流程 |
| **数据库索引** | 在key、creator、engineType字段建立索引 | 提高查询速度 |
